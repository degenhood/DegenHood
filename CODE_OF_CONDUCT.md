# Code of conduct

DegenHood contributors are expected to keep technical collaboration safe, direct, and respectful.

## Expected behavior

- Discuss code and evidence rather than attacking people.
- Welcome good-faith questions and differing experience levels.
- Respect privacy, security boundaries, and coordinated disclosure.
- Give actionable feedback and acknowledge uncertainty.
- Avoid market manipulation, undisclosed promotion, harassment, threats, or discrimination.

## Unacceptable behavior

Harassment, doxxing, deliberate disclosure of secrets, attempts to move another person's funds,
malicious disruption, and sexualized or discriminatory conduct are not acceptable in project
spaces.

Repository maintainers may edit or remove contributions and restrict participation when needed to
protect contributors, users, or the project. Report conduct concerns privately through the
repository maintainers. Security vulnerabilities must follow [SECURITY.md](SECURITY.md).
